# NOTE ON OFFLINE / SANDBOXED EXECUTION
# --------------------------------------------------------------------------
# This project was authored and smoke-tested in a sandboxed environment
# with NO network access, so sentence-transformers, faiss-cpu, nltk,
# rouge-score, bert-score, lightgbm, and openai could not be installed or
# their model weights downloaded. Every module that depends on one of
# these packages (src/embeddings.py, src/retrieval.py, src/evaluation.py,
# src/reply_generator.py, src/escalation.py, src/intent_classifier.py)
# detects the missing dependency at runtime and transparently falls back
# to a dependency-free equivalent (TF-IDF+SVD embeddings, numpy
# brute-force search, hand-rolled BLEU/ROUGE, logistic regression instead
# of LightGBM, template-based replies instead of live LLM calls) so the
# full pipeline still runs and every STEP produces real, non-fabricated
# output. Installing the packages above and providing OPENAI_API_KEY
# upgrades each fallback to its production-quality counterpart with zero
# code changes -- see README.md "Reproducing with full dependencies".
